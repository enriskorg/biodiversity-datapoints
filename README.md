# Datapoints de Biodiversidad – Crosswalk de 7 estándares

Herramienta interactiva para explorar y comparar los requisitos de divulgación relacionados con biodiversidad y naturaleza en:

- ESRS E4
- GRI 101 Biodiversity 2024
- TNFD
- CDP 2024
- SBTi Net-Zero Standard v2
- IFRS S1
- IFRS S2

## Funcionalidades

- Visualización de 87 datapoints.
- Búsqueda por texto libre.
- Filtros por estándar, categoría y tipo de dato.
- Matriz de convergencia entre estándares.
- Exportación a CSV.
- Interfaz web sin dependencias externas.

## Uso

Abrir directamente `index.html` en cualquier navegador moderno.

## Aviso

Los requisitos se presentan de forma parafraseada y resumida. No constituyen una reproducción oficial de los estándares originales.
